# 多平台安装路径

本工作流的核心是提示词与结构，**不依赖任何脚本**，因此在任何支持自定义指令的平台上都能用。

---

## 支持 Skill 标准的平台

`install.sh` 会自动探测以下目录并安装：

| 平台 | 安装路径 |
| --- | --- |
| Claude Code | `~/.claude/skills/` |
| Codex CLI | `~/.codex/skills/` |
| Cursor | `~/.cursor/skills/` |
| 通用 Agent Skill 标准 | `~/.agents/skills/` |

安装后，说出触发词即可调用：

```
研判一下 XX 公司
帮我准备下周的客户拜访
这个招标参数帮我看一下
```

---

## 纯聊天窗口（ChatGPT / Kimi / 豆包 / 通义等）

功能完全不打折，只是需要手动粘贴。

**步骤**：

1. 新开一个对话
2. 粘贴 `SKILL.md` 的第 0、6、7 节（三条铁律 + 五角色模型 + 输出纪律）
3. 粘贴你要用的那个模块的 `prompts/*.md`
4. 填入客户信息
5. 用 `templates/` 下对应的模板校对输出格式

**建议**：把第 2 步的内容存成一个「自定义指令」或「预设」，之后每次直接用。

---

## 配合行业包使用

在粘贴模块提示词之后，追加一句：

```
另外加载以下行业包，它会覆盖默认的角色模型与采购流程：
（粘贴 industry-packs/xxx.md 的内容）
```

---

## 隐私提醒

**在联网的大模型服务上使用时，先脱敏。**

具体来说：

- 真实客户名可以用代号替代（「A 公司」）
- 不要粘贴未公开的采购金额、内部人员信息
- 不要粘贴带客户水印的招标文件原件

**本工作流本身不收集任何数据**，但你使用的大模型平台可能会。这是两回事。
